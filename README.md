# Rock-Paper-Scissors-Game

🎯 About The Project:

A modern and interactive version of the classic Rock Paper Scissors game built using HTML, CSS, and JavaScript.
## 🎯 Features

- 👊🖐️✌️ Visual hand signs that animate like real gameplay
- 🎵 Sound effects for win, lose, tie, and round results
- 🏁 Round-based system playing (Best of 5 matches)
- 📜 Rules displayed clearly for new users

## 📋 Rules

- One round contains **5 matches**.
- Win at least **3 out of 5** to win the round.
- Each match will show your and the computer's hand.
- Play again as many rounds as you like!

## 🛠️ Tech Stack

- **HTML** – structure and layout
- **CSS** – styling and animations
- **JavaScript** – logic, interactivity, and sounds
