# Rock-Paper-Scissors-Game:-

🎯 About The Project:

A modern and interactive version of the classic Rock Paper Scissors game built using HTML, CSS, and JavaScript.

This project goes beyond the traditional game by adding:
## 🎯 Features

- 👊🖐️✌️ Visual hand signs that animate like real gameplay
- 🎵 Sound effects for win, lose, tie, and round results
- 🏆 Best-of-5 round system
- 📜 Rules displayed clearly for new users
- ⚡ Real-time result updates

  Whether you're playing for fun or exploring front-end development concepts, this projects can delivers an engaging experiment.
  
## 📋 Rules:

- One round contains total **5 matches**.
- Win at least **3  rounds out of 5** to win the round.
- Each rounds will show your and the computer's hand.
- Play again as many rounds as you want to play!

## 🛠️ Tech Stack:

- **HTML** – structure and layout
- **CSS** – styling and animations
- **JavaScript** – logic, interactivity, and sounds
